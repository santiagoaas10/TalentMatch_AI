# Explicar el código (modo aprendizaje)

El usuario está en un bootcamp y quiere entender cada línea que se escribe.
Cada vez que escribas o edites código en este proyecto:

## Antes
- Explica en español qué vas a implementar y por qué ese enfoque.
- Si hay un patrón (async, dependency injection, Pydantic, structured output,
  RAG, etc.), nómbralo y di en una línea qué problema resuelve.

## Después
- Repasa el código escrito en lenguaje simple: qué hace cada parte clave.
- Señala decisiones no obvias (por qué async, por qué este tipo, por qué este
  módulo y no otro).

Mantén el estilo: español con términos técnicos en inglés. Conciso, no un ensayo.
